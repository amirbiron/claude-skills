# Design System MD — סקיל להחלת מערכת עיצוב

## סקירה

באמצעות ה‑CLI‏ getdesign.md מושכים את מערכת העיצוב של מותגים מובילים בעולם (צבעים, גופנים, ריווח, קומפוננטות) כקובץ DESIGN.md. Claude Code מפנה אליו בזמן יצירת ממשק ומחיל עיצוב באיכות מקצועית באופן עקבי.

## מתי להשתמש

- ביצירת דף נחיתה / LP
- בבניית ממשק לאפליקציית ווב או לדשבורד
- בשיפור איכות העיצוב של ממשק קיים
- בשחזור מראה בסגנון מותג מסוים
- בהפקת ויזואלים — תמונות פתיח, באנרים וכדומה

**מילות הפעלה**: עיצוב, UI, LP, דף נחיתה, בסגנון Apple, מערכת עיצוב, DESIGN.md, מראה, מותג

## הוראות

### שלב 1: בחירת מערכת העיצוב

בחר מותג לפי אופי הפרויקט:

| שימוש | מותגים מומלצים |
|------|-------------|
| פרימיום / יוקרה | apple, ferrari, lamborghini, bmw |
| SaaS / דשבורד | linear.app, stripe, vercel, supabase |
| ידידותי / קליל | notion, airbnb, figma, cal |
| AI / טכנולוגיה | claude, cursor, משפחת openai, xai |
| פיננסים / אמינות | coinbase, revolut, wise |
| תיעוד / קריאוּת | mintlify, hashicorp, ibm |

לרשימה המלאה: `npx getdesign@latest list`

### שלב 2: משיכת DESIGN.md

```bash
# מציבים בשורש הפרויקט
npx getdesign@latest add <brand>

# דוגמה: בסגנון Apple
npx getdesign@latest add apple

# אפשר גם למשוך כמה מותגים כדי להשוות ולמזג
npx getdesign@latest add stripe --out ./design-refs/stripe-DESIGN.md
npx getdesign@latest add apple --out ./design-refs/apple-DESIGN.md
```

### שלב 3: שילוב ב‑CLAUDE.md

הוסף את הבא ל‑CLAUDE.md של הפרויקט:

```markdown
## Design System
בכל יצירה או תיקון של ממשק — חובה להפנות ל‑DESIGN.md.
צבעים, גופנים, ריווח וסגנון קומפוננטות ייקבעו לפי ההגדרות ב‑DESIGN.md.
אין להשתמש בצבעים או בגופנים משלך על דעת עצמך.
```

### שלב 4: יצירת הממשק

צור קומפוננטות ועמודים תוך הפניה ל‑DESIGN.md:

```
צור עמוד תוכניות תמחור לפי מערכת העיצוב שב‑DESIGN.md.
צבעים, גופנים, ריווח וסגנון כפתורים — הכול בהתאם ל‑DESIGN.md.
```

### שלב 5: בדיקת איכות

ודא שהממשק שנוצר תואם ל‑DESIGN.md:

- התאמת קודי צבע
- התאמת משפחת גופן וגודל
- עמידה בריווח (בסיס 8px וכדומה)
- התאמת סגנון קומפוננטות (רדיוס פינות, צללים וכדומה)

## מבנה תשעת הסעיפים של DESIGN.md

1. **Visual Theme & Atmosphere** — פילוסופיית העיצוב
2. **Color Palette & Roles** — הגדרת צבעים (ערכי Hex + תפקיד)
3. **Typography Rules** — טבלת היררכיית גופנים
4. **Component Stylings** — כפתורים, כרטיסים, ניווט וכדומה
5. **Layout Principles** — ריווח ורשת
6. **Depth & Elevation** — צללים ושכבות
7. **Do's and Don'ts** — מעקות בטיחות
8. **Responsive Behavior** — נקודות שבירה
9. **Agent Prompt Guide** — עיון מהיר לסוכני AI

## יצירת DESIGN.md מותאם

להתאמה אישית על בסיס מותג קיים:

1. משוך את ה‑DESIGN.md של מותג הבסיס
2. החלף את ה‑Color Palette בלבד (לצבעי המותג שלך)
3. שנה את הגופנים ב‑Typography
4. כוונן את ה‑Component Stylings

## קווים מנחים

1. **בחירת מותג נגזרת ממטרה**: לא "מה נראה מגניב" אלא "למי מוכרים ומה"
2. **מיזוג עד שני מותגים**: יותר מזה מפרק את העקביות
3. **אל תדרוס את DESIGN.md**: גרסה מותאמת נשמרת בקובץ נפרד
4. **אל תשכח רספונסיביות**: לך לפי נקודות השבירה שמוגדרות ב‑DESIGN.md
5. **כבד את ה‑Do's and Don'ts**: אל תתעלם ממעקות המותג
