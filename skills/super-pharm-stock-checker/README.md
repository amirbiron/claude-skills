# בודק מלאי סופר-פארם

סקיל (Skill) לסוכני AI — בודק **זמינות מלאי בזמן אמת** בסניפי סופר-פארם ברחבי ישראל, לפי שם מוצר ועיר.

> **כתב ויתור**: כלי לא רשמי, אינו קשור לסופר-פארם ישראל ואינו מאושר על ידה. המידע עשוי שלא לשקף את המלאי בפועל — יש לאמת מול הסניף לפני הגעה.

## מה יש כאן

| קובץ / תיקייה | תיאור |
|---------------|--------|
| `SKILL_HE.md` | הוראות מלאות לסוכן — **עברית** |
| `SKILL.md` | אותן הוראות — **אנגלית** |
| `super-pharm-stock-checker.skill` | אריזת הסקיל לשימוש בפלטפורמות שתומכות בפורמט `.skill` |
| `references/api-reference.md` | תיעוד נקודות ה-API, סכמות ושדות |
| `scripts/stock-check.js` | חלופת CLI — קריאה ישירה ל-API מהטרמינל (ללא תוסף Chrome) |

## דרישות וזרימות עבודה

**MCP (מומלץ כשה-CLI נכשל):** הזרימה המלאה דרך הדפדפן משתמשת ב-**[Claude in Chrome](https://support.claude.com/en/articles/12012173-get-started-with-claude-in-chrome)** — אוטומציה בטאב Chrome באמצעות כלי MCP (`mcp__Claude_in_Chrome__*`). זו הדרך היציבה כשצריך לבדוק מלאי דרך האפליקציה הרשמית.

**CLI:** אפשר גם להריץ את `scripts/stock-check.js` מהטרמינל (ראו `SKILL_HE.md`, סעיף «חלופת CLI»), אבל **לא תמיד זה עובד** — תלוי ברשת, בחסימות או בשינויים בצד השרת. **אם ה-CLI לא מצליח** — יש לעבור ל-**MCP** (Claude in Chrome) ולבצע את השלבים שם.
